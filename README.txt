Ryan Choi Music Journal — GitHub Pages

1. Extract the ZIP.
2. Create a public GitHub repository.
3. Choose Add file > Upload files, then drag index.html into the repository root. Do not upload the ZIP itself.
4. Select Commit changes.
5. Go to Settings > Pages. Select Deploy from a branch, choose main and /(root), and click Save.
6. Return to Pages settings to find your website address.

The other Ryan Choi pages in the navigation still link to their existing websites. External streaming links require internet access.
